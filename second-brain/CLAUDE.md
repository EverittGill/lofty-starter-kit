## How memory works here

- **One fact, one file** in `memory/`, with this header:

  ```
  ---
  name: short-slug
  description: one line, used to decide when this memory matters
  type: user | feedback | project | reference
  ---
  ```
  `user` = who I am · `feedback` = how I want Claude to work (include why) · `project` = ongoing work
  with dates · `reference` = where things live (links, logins I use, which tool does what).
- After writing a memory file, add one line to `memory/MEMORY.md`: `- [Title](file.md) — hook`.
- Update an existing memory instead of making a duplicate. Delete memories that turn out wrong.
- Write dates as real dates (2026-11-19), never "yesterday" or "next week".
- Keep `MEMORY.md` under 20 lines. Move stale entries to `memory/archive/`.
