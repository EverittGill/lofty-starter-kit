# Lofty Starter Kit

The KTS follow-up system (47 email drips, 490 emails) for a Lofty account, plus a blank Claude Code
second brain.

**To use it:** open a terminal in this folder, run `claude`, and say **"set me up"**. Claude reads
`START-HERE.md` and walks you through it. Nothing is sent to your leads during setup: every drip
arrives in Lofty as a personal draft with auto-apply off.

Private. Please don't share it further.
